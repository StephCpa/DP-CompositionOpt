# η 稳定性与 Top-K 跟踪审计（2026-10-08）

本文件记录 EControl 参数 `eta` 的稳定性审计。所有数值都来自两个已提交脚本及其输出：

| 内容 | 脚本 | 输出 |
|---|---|---|
| 闭式稳定区、EC-matrix 增益、二次 Lyapunov 证书 | `repro/quadratic_certificate_search.py` | `experiments/quadratic_certificate_20261008.json` |
| 递推经验增益、box-LS 的 η 扫描与 Top-K 支撑记录、h 投影压力测试 | `repro/eta_gain_probe.py` | `experiments/eta_gain_scan_20261008.json` |

**结论分级。** 第 2 节是代数结论。第 3 节的证书是经特征值复核的充分条件（启发式搜索，"未找到"不代表不存在）。第 4–6 节是有限轨迹经验诊断，不是定理。

## 1. 对象与记号

代码（`eta=topk_frac`）的更新顺序为
`delta_t = u_t - h_{t-1} - eta e_t`，`q_t = TopK(delta_t)`，`h_t = h_{t-1} + q_t`，`e_{t+1} = e_t + h_t - u_t`。
在 h/e 投影都未激活时，它等价于闭合草案 §5.4 的 EC-rec：

```text
e_{t+1}     = (1-eta) e_t + q_t - delta_t
delta_{t+1} = (1+eta)(delta_t - q_t) + eta^2 e_t + (u_{t+1} - u_t)
h_t - u_t   = q_t - delta_t - eta e_t
```

**增益定义。** 记 `kappa = k/d`，`chi = sqrt(1-kappa)`，`du_t = u_{t+1} - u_t`。e-增益 `G_e` 与 h-增益 `G_h` 指稳态界

```text
limsup_t ||e_t||       <= G_e * sup_s ||du_s||
limsup_t ||h_t - u_t|| <= G_h * sup_s ||du_s||
```

代码从 `h_{-1}=0` 启动，所以 `delta_0 = u_0`。由此产生的衰减瞬态（量级 `rho^t sqrt(V_0)`）不计入增益。

## 2. EC-matrix 路线的闭式稳定区（代数结论）

对 `0 < eta <= 1`，`M_delta = [[1-eta, chi], [eta^2, (1+eta) chi]]` 是非负矩阵。`rho(M_delta) < 1` 当且仅当 `I - M_delta` 是非奇异 M-矩阵，即对角元为正且 `det(I-M_delta) = eta (1 - chi - 2 eta chi) > 0`。因此

```text
rho(M_delta) < 1   <=>   eta < eta_crit := (1/sqrt(1-kappa) - 1) / 2 .
```

`kappa = 0.1` 时 `eta_crit = 0.02705`。数值复核：`eta_crit ± 1e-4` 处 `rho = 0.99990 / 1.00010`。Paper 3 推荐值 `eta = 0.01803` 落在稳定区内，代码默认值 `eta = 0.1` 不在。

稳定时，比较系统给出 `G_e = chi / (eta (1 - chi - 2 eta chi))`，以及 `G_h = 2 chi / (1 - chi - 2 eta chi)`（由 `||h-u|| <= chi ||delta|| + eta ||e||` 得到）。

## 3. 二次 Lyapunov 证书（充分条件，已复核）

EC-matrix 只用了 `||delta - q|| <= chi ||delta||`。证书搜索额外使用 Top-K 的正交分解，约束为：

1. `<q, delta - q> = 0`（选中与未选中坐标的支撑不相交）；
2. `||delta - q||^2 <= (1 - kappa) ||delta||^2`。

搜索的形式是 `V = [e; delta]^T (P ⊗ I_d) [e; delta]`。分块标量的 `P` 使证书与维数 `d` 无关。S-procedure 条件为

```text
V' - rho^2 V - c ||du||^2 + lambda_1 <q, delta-q> + lambda_2 [(1-kappa)||delta||^2 - ||delta-q||^2]  ⪯ 0 .
```

对固定 `rho`，最小的 `c` 由 w 块的 Schur 补给出；`mu_e = p11 - p12^2/p22` 下界 `V/||e||^2`。于是 `G_e = sqrt(c / ((1-rho^2) mu_e))`。h-增益由第二个 S-procedure 给出：`||q - delta - eta e||^2 <= beta V`，`G_h = sqrt(beta c / (1-rho^2))`。

同一不等式取期望后，也给出均方界：`limsup E||e_t||^2 <= G_e^2 sup_s E||du_s||^2`。

**复核与容差。** 每个报告的证书都经特征值复核：`P > 0`，乘子满足符号约束，耗散矩阵最大特征值在 rho 搜索中 `< -1e-9`；增益证书在 `c` 上加 `1e-7` 相对余量后，最大特征值 `<= 1e-9 × 矩阵尺度`。搜索是确定性的纯 numpy Nelder–Mead 加 rho 二分（`[0.9, 1.2]`，12 步）。

**"未找到"的含义。** 它只说明该启发式搜索在这一函数类里没有找到证书，既不证明证书不存在，也不说明算法不稳定。

`kappa = 0.1` 的结果：

| eta | EC-matrix rho | EC-matrix `G_e / G_h` | 二次证书最小 rho | 二次证书 `G_e / G_h`（所用 rho） | 加 h 扇区约束后的最小 rho |
|---:|---:|---:|---:|---:|---:|
| 0.1（代码默认） | 1.0928 | — | 1.0399（未认证） | — | 1.1079 |
| 0.05 | 1.0269 | — | 0.9963 | 5399 / 391（0.9982） | 1.1251 |
| 0.027 | 0.99995 | 400169 / 21609 | 0.9811 | 1443 / 58（0.9868） | 1.0923 |
| 0.018（Paper 3） | 0.9932 | 3071 / 111 | 0.9847 | 1481 / 41.5（0.9862） | 1.0877 |
| 0.0135 | 0.9921 | 2734 / 74 | 0.9887 | 1938 / 53（0.9943） | 1.0204 |

解读：

- 二次证书把可证明区从 `eta < 0.027` 扩到至少 `eta = 0.05`，并把 Paper 3 η 下的常数降到约一半（e：3071 → 1481；h：111 → 41.5）。但 `eta = 0.1` 仍无法用这两条 Top-K 事实认证。
- 证书常数仍远大于第 4 节的经验最坏情况：e-增益约大 6–70 倍，h-增益约大 10–90 倍。
- 表中增益是搜索得到的上界，依赖 rho 网格与随机初值；不同 eta 之间的非单调（如 0.0135 比 0.018 大）不应解读为结构性结论。

## 4. 经验增益（有限轨迹，最坏情况增益的下界）

`d = 10, k = 1`，每步 `||du_t|| = 1`。ramp 是固定方向，random 是随机方向，greedy 是单步前瞻对抗。

要点：

- `eta = 0.1` 不能被认证，但在所有测试输入下都有界。"不能认证"不等于"不稳定"。

- h 跟踪增益约为 4，几乎与 eta 无关。h-margin 由 Top-K 跟踪决定，而不是由 eta 决定。

## 6. h 投影作为饱和算子

**扇区约束。** 若 `||u_t|| <= B_h`，球投影残差 `p = h_raw - Pi(h_raw)` 满足 `<p, (h_raw - u) - p> >= 0`。这是标准 absolute-stability（扇区）约束。把它加入第 3 节的 S-procedure 后，在 `eta ∈ {0.0135, …, 0.1}` 上最小 rho 均大于 1（表中最后一列）。因此"把 h 投影当作一般扇区非线性"的论证不能给出证书；若要证明，需要利用球投影的径向结构（`p` 与 `h_raw` 共线，激活时 `||h_t|| = B_h`）。

**仿真。** 令 `u_t` 始终位于 `0.95 B_h` 球内（旋转输入与随机游走输入，`T = 20000`）。h 投影最多在 52% 的轮次中激活，但 `sup ||e||` 从不大于无投影版本，例如 3.46 对 4.09、5.75 对 7.87。

**必要条件。** h 投影无害依赖 `||u_t|| <= B_h`。当 `C_g >= C_0` 时有 `u = v`、`||v|| <= C_0`，所以 `C_0 <= B_h` 是确定性的充分条件。当前主线 `C_0 = 1.5 > B_h = 1` 不满足它（实测 `||u|| <= 0.59` 只是经验事实）。`||u|| > B_h` 持续成立时，e 线性增长（dense overload 压力测试已展示）。

## 7. 对证明路线的含义

1. **以 `sup ||du||` 为输入的逐路径 margin 界在当前实验中注定失败。** 即使用经验最坏增益 4 和本扫描中的 `max ||du|| ≈ 0.38–0.47`，也有 `0.59 + 4 × 0.38 ≈ 2.1 > B_h = 1`；而真实 `max ||h_raw|| < 0.7`。原因是真实 `du` 以新鲜高斯噪声驱动的 movement 为主，并非持续的 ramp。所以需要利用输入结构（均方或独立性），而不是最坏情况 sup。
2. **均方路线不需要高概率事件。** 在证书覆盖的动力学下，`V_{t+1} <= rho^2 V_t + c ||du_t||^2` 取期望即可。结合 `||du_t|| <= L_bar ||x_t - x_{t-1}|| <= L_bar ||y_{t-1}|| / gamma`（逐样本 clip 是 1-Lipschitz，盒/单纯形 prox 非扩张，固定 gamma）以及 `E||y||^2 <= B_h^2 + d sigma^2`，DA 界中的 error-feedback 项为 `O(G_e^2 L_bar^2 (B_h^2 + d sigma^2) / gamma^3)`，再加 `O(1/(gamma T))` 的瞬态项。当 `gamma >> G_e L_bar` 时它低于噪声主项 `2 d sigma^2 / gamma`。因此大常数影响的是起效的 horizon，而不是收敛阶。该路线的前提是 h 投影不激活或已被证书覆盖，这正是第 6 节未解决的部分。
3. **一个可选的机制变体。** 把 `B_h` 投影从状态更新移到发布端：curator 在平均前对每个 `h_i` 取 `clip_{B_h}`，客户端内部的 EControl 状态不再投影。隐私不变（替换一个客户端仍只改变一个球内向量，敏感度 `2 B_h / n`），EControl 动力学恰好是无投影递推，第 3 节证书可以直接使用。代价是发布端 clip 残差以带符号运行和的形式直接进入 `E_t`，需要单独控制。这只是候选设计，尚未实现或评估。

## 9. 不能据此声称

- `eta = 0.1` 不稳定（它只是未被认证，经验上有界）；
- 证书搜索失败意味着不存在 Lyapunov 函数或算法发散；
- 经验增益等于最坏情况增益，或第 4 节的数值是证书；
- 改用 Paper 3 的 eta 会改善效用或误差能量（实测相反：误差能量更大，效用不变）；
- h 投影作为一般扇区非线性已被证明无害；
- 第 5 节单一合成任务的结果可推广到 softmax 或 simplex。
